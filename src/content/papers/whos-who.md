Trace links between documentation and architecture need to know which parts of
a text talk about which architecture entities. This journal article, which
extends earlier work presented at ICSA 2025, uses large language models to recognize
architecture entities in software documentation and builds traceability link
recovery on top of that, with the language model doing the part that used to
need hand-crafted heuristics.
