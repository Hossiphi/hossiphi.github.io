Research on secure software engineering needs realistic systems whose
security-relevant artifacts are available together. The EVerest dataset is
built around [EVerest](https://lfenergy.org/projects/everest/), an open-source
software stack for electric-vehicle charging, and collects the artifacts
around it so that approaches for security requirements, architecture analysis
and traceability can be evaluated on a real energy system.
