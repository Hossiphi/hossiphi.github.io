[ARDoCo](https://ardoco.de/) recovers trace links between natural-language
architecture documentation, architecture models and code. This tool paper
makes those approaches usable outside of research prototypes: a REST API to run
them as a service, TraceView to inspect the recovered trace links, and TraceViz
to visualize them across artifacts.
