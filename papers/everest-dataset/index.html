The EVerest Dataset for Secure Software Engineering11 citation on Google Scholar

Sophie CoralloiD, Debora Grupp, Dominik FuchßiD, Jan KeimiD, Frederik Reiche, Tobias HeyiD, and Anne KoziolekiD

ASE2026Published at 41st IEEE/ACM International Conference on Automated Software Engineering (ASE 2026) — Tools and Datasets Track

Proceedings of the 41st IEEE/ACM international conference on automated software engineering

Research on secure software engineering needs realistic systems whose security-relevant artifacts are available together. The EVerest dataset is built around EVerest, an open-source software stack for electric-vehicle charging, and collects the artifacts around it so that approaches for security requirements, architecture analysis and traceability can be evaluated on a real energy system.
